# Sakkan Properties AI Concierge

## Architecture

Broker → Chainlit → LangGraph → Triage → Property Finder → Mortgage Analyst → Communication → Human Approval → Broker.

Property Finder uses Qdrant RAG with deterministic listing tools. Mortgage calculations use a validated MCP tool. Client memory is scoped by client ID. Structured logging records a trace ID across the request.

## Agent Roles

Triage identifies request intent and client information. Property Finder combines semantic retrieval with deterministic listing filters. Mortgage Analyst calculates mortgage figures using the validated calculator. Communication drafts client messages using supplied property facts and listing IDs.

## RAG and Memory

The corpus contains 60 short synthetic documents. Gemini embeddings are stored in Qdrant, and retrieval returns document IDs with their text.

Memory is scoped to client IDs. Memory writes require explicit consent, and `/forget <client_id>` removes the client's stored memory without exposing its contents.

## Human Approval

Client-facing drafts generated by the communication agent are paused for broker review using Approve, Reject, or Edit. A draft is only returned as the final client-facing message after the broker approves or edits it.

## Evaluation

The test suite evaluates four primary dimensions:

* **Faithfulness:** whether responses remain grounded in retrieved information.
* **Consent Respect:** whether memory actions respect explicit user consent.
* **HiL Respect:** whether client-facing drafts follow the broker approval decision.
* **Tool-Call Presence:** whether required tools are invoked for tool-dependent requests.

The evaluation also checks listing provenance and required Human-in-the-Loop behavior. The generated evaluation results are stored in `outputs/eval_report.json`.

## Limitations

The project uses a small fictional corpus and deterministic local tools. The scheduling tool is simulated rather than connected to a real calendar or booking system.

A production deployment would require authentication, stronger access control, persistent audit policies, a production scheduling backend, and more extensive evaluation data.

## Responsible AI

The system is designed to ground property responses in retrieved and tool-provided information, avoid unsupported property claims, scope client memory by client ID, require consent for memory writes, and require broker approval before returning communication drafts as client-facing messages.
